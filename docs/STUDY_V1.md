## 问题与固定协议

| 参数包 | DPO beta | PPO KL 系数 | seeds |
|---|---:|---:|---|
| standard | 0.1 | 0.05 | 42、43、44 |
| low | 0.05 | 0 | 42、43、44 |
| high | 0.2 | 0.1 | 42、43、44 |

DPO 与 PPO 分别从 SFT 分叉，PPO 不读取 DPO 权重。将两项参数放进同一配置包只是运行组织方式，不研究二者的联合交互。汇总前必须核对相同 seed 的三个包具有相同 SFT 和 RM 权重指纹。每包重新完成四阶段，使每个输出目录具有独立、完整的训练身份；额外重训成本如实计入。

每个运行的 SFT/RM/DPO 各 300 次优化器更新，batch 1、梯度累积 4。PPO 为 96 批、每批 4 条采样回答、2 个 epoch、minibatch 2，共 384 次优化器更新。384 条采样不等于 384 个独立原文。固定步数不代表收敛，也不表示 DPO 与 PPO 消耗相同计算量。

输入预算为 prompt 576、response 96 token。离线审计表明，576 容纳当前 train/valid 中提供的原文及任务 marker；96 仍截断 train 中 4 条 chosen 和 2 条 rejected，valid 无摘要截断。该覆盖结论只针对数据记录，不保证上游网页文章完整。详细记录见 `reports/context-audit-20261020.json`。

## 评估与解释

当前训练分区为 1,024 个偏好对、268 个独立原文，valid 为 128 对、34 个独立原文。来源是公开数据集 train 的前 3,000 行再分组划分，不是官方留出集或均匀随机样本。不同随机种子会再次评估同样的 34 个原文，不能把它们视为 102 个独立样本。

每组使用相同 valid 输入和固定 greedy 解码，比较 Base/SFT/DPO/PPO 的 chosen token NLL、长度、重复三元组比例和训练 RM 评分。NLL 和重复率仅为诊断；训练 RM 评分尤其不能当作 PPO 的独立质量证据。RM 偏好准确率附有限样本区间。输出每 seed 的数值及三 seed 均值、样本标准差；按原文配对 bootstrap 区间描述某一已训练模型在该验证集上的不确定性，不能替代随机种子波动。

导出的人工盲评表保持空白，实际标注数量为 0 时胜率为空。后续标注应使用独立副本，保留原始评估目录的哈希。真正的效果结论需要独立人工评价及另行固定的最终测试协议，本轮不自动填入胜率或简历效果数字。
